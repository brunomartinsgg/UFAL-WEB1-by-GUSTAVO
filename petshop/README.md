# PetShop Amigo Fiel

Site de um petshop, feito com React para a disciplina de Programação Web I (UFAL).

## Sobre o projeto

O site apresenta os serviços do petshop (banho e tosa, consulta veterinária e
hospedagem) e um botão de contato pelo WhatsApp. O objetivo é reunir em um só
lugar as informações que o tutor precisa para conhecer o petshop.

## Tecnologias

- React
- HTML e CSS
- Vite

## Como executar

1. Instale o Node.js.
2. Clone o repositório e entre na pasta do projeto.
3. Instale as dependências:

```bash
npm install
```

4. Rode o projeto:

```bash
npm run dev
```

5. Abra no navegador o endereço que aparecer no terminal (normalmente http://localhost:5173).
